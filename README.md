# のむログ

「つづけるミカタ」の後継として作った、iPhone 向けの服薬リマインダー＆記録アプリです。
GitHub Pages で公開する Web アプリ(PWA)で、ホーム画面に追加すると普通のアプリのように使えます。

## できること

- **服用時刻のプッシュ通知**:記録がなければ 10〜60分おきに再通知(回数も設定可)
- **休薬日・記録済みの日は通知しない**(つづけるミカタで不満の多かった点)
- **服用パターンを自由に設定**:21+7 / 24+4 / 28日連続 / 日数を自分で決める / **連続服用(所定日数を飲んだ後、休薬開始日を自分で選ぶ)**
  - 連続服用では「◯日飲んだら休薬を選べる」「上限◯日」「休薬◯日」を設定。上限が近づくと警告
  - 選んだ休薬は取り消し可能
- **シートの途中からでも開始できる**(今日が服用/休薬の何日目かを入力)
- **錠剤シート画面とカレンダー**で記録を確認。**過去の日付もタップして修正できる**
- 昨日の記録がないと今日の画面でお知らせ → 「飲んでいた」「飲み忘れた」を選べる
- **残り錠数**の管理と、残りわずかになったときの警告(通知文にも表示)
- **受診予定**(前日に通知)、**かかりつけの電話番号**(ワンタップで発信)
- **飲み忘れたときの対処メモ**(添付文書や医師の指示を自分で登録)
- **4桁パスコードロック**(1分以上閉じていたら再ロック)
- **バックアップ**の書き出し/読み込み(機種変更用)

## プライバシー

記録(飲んだ時刻・メモ・薬の名前・受診先など)はすべて **iPhone の中だけ** に保存されます。
サーバー(Firestore)に送るのは、通知に必要な **通知時刻・休薬日の日付・直近の飲んだ日付・受診日の前日・残りわずかかどうか** だけで、匿名ログインの ID にひもづきます。

## 公開までの手順(参考)

これまでのアプリと同じ **Firebase + GitHub Pages** 構成です。違いは、決まった時刻に通知を送るために **Cloud Functions(定期実行)** を使う点で、Firebase を **Blaze(従量課金)プラン** にする必要があります。1人で使う規模なら無料枠に収まります(5分おきの実行で月約9,000回。無料枠は月200万回)。

### 1. Firebase プロジェクトを作る

1. [Firebase コンソール](https://console.firebase.google.com/) で新しいプロジェクトを作成(例: `nomu-log`)
2. **Blaze プランにアップグレード** → Google Cloud の「予算とアラート」で **月100円などの予算アラート** を設定しておくと安心
3. **Authentication** → ログイン方法 → **匿名** を有効にする
4. **Firestore Database** → データベースを作成(ロケーション `asia-northeast1`、本番モード)
5. **プロジェクトの設定 → 全般 → マイアプリ** で「ウェブアプリ」を追加し、表示された `firebaseConfig` の値を `js/firebase-config.js` に貼り付け
6. **プロジェクトの設定 → Cloud Messaging → ウェブプッシュ証明書** で「鍵ペアを生成」し、その値を `js/firebase-config.js` の `vapidKey` に貼り付け

### 2. 通知サーバー(Cloud Functions)とルールをデプロイ

パソコンのターミナルで、このフォルダに移動して実行します。

```bash
npm install -g firebase-tools
firebase login
firebase use --add            # 1. で作ったプロジェクトを選ぶ
cd functions && npm install && cd ..
firebase deploy --only functions,firestore:rules
```

初回は Cloud Scheduler などの API を有効にするか聞かれるので「Y」で進めます。

### 3. GitHub Pages で公開

1. GitHub で新しいリポジトリを作成(例: `Kota422531/nomu-log`)
2. このフォルダの中身をすべてアップロード(`functions/node_modules` は不要)
3. **Settings → Pages** で `main` ブランチ / `/(root)` を選んで保存
4. 数分後、`https://kota422531.github.io/nomu-log/` で開けます
5. Google Cloud コンソールの **APIとサービス → 認証情報** で、Firebase の API キーに **ウェブサイトの制限** `https://kota422531.github.io/*` を設定

### 4. iPhone での使い始め

1. **Safari** で公開した URL を開く
2. 共有ボタン → **「ホーム画面に追加」**
3. ホーム画面の「のむログ」アイコンから開き、服用パターンを設定
4. **設定 → 通知をオンにする** → 許可
5. **テスト通知** を押し、5分以内に届けば完了

> iPhone のプッシュ通知は iOS 16.4 以降、かつホーム画面に追加したアプリでのみ動きます。集中モードで通知が止まらないよう、必要なら集中モードの許可アプリに「のむログ」を追加してください。

## 更新するとき

ファイルを直して GitHub にアップロードしたら、`sw.js` の先頭の `CACHE = 'nomulog-v1'` の数字を上げてください(古い画面がキャッシュに残るのを防ぎます)。

## ファイル構成

```
index.html            画面の骨組み
css/app.css           見た目
js/app.js             画面と操作
js/cycle.js           服用周期の計算(休薬日・何日目か・残り錠数)
js/store.js           端末内の保存・バックアップ
js/push.js            通知の登録とサーバーへの同期
js/firebase-config.js Firebase の設定(ここに貼り付け)
sw.js                 オフライン対応と通知の表示
functions/            5分おきに通知を送るサーバー処理
firestore.rules       データベースのアクセス制限
tests/                周期計算のテスト(node tests/cycle.test.mjs)
```

## 注意

服用の記録とお知らせのためのアプリです。飲み忘れたときの対応や休薬のタイミングなど、医療上の判断は医師・薬剤師の指示に従ってください。
